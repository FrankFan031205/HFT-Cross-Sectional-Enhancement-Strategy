# FactorModel Stage README

## 1. Purpose

The `FactorModel` stage converts handcrafted high-frequency microstructure factors into supervised hidden alpha signals.

The workflow is:

```text
raw microstructure factors
        ↓
preprocessing
        ↓
machine learning / neural network models
        ↓
hidden factor prediction
        ↓
out-of-sample factor evaluation
        ↓
pricing / market-making input
```

The current target is:

```text
label_60
```

`label_60` represents the future 60-horizon mid-price return:

```text
label_60 = (future_mid_price_60 - current_mid_price) / current_mid_price
```

The model output is interpreted as a supervised hidden alpha factor, for example:

```text
hidden_factor_lgbm_h60
hidden_factor_attention_h60
hidden_factor_lookback_attention_h60
```

A higher hidden factor means the model expects stronger future return over the prediction horizon.

## 4. Preprocessing

Preprocessing converts raw factor data into model-ready data.

Main output:

```text
data/processed/factor_features_202410_100_processed.csv
```

Typical preprocessing steps:

```text
1. Replace inf and -inf
2. Fill missing factor values
3. Clip extreme values by quantile
4. Cross-sectional z-score normalization by datetime
5. Optional label winsorization
```

Cross-sectional z-score normalization is done at each timestamp:

```text
factor_zscore = (factor - cross_section_mean) / cross_section_std
```

Run:

```bash
cd /home/fwz/projects/HFT_010-dev_fwz/FactorModel

python src/preprocess.py --config configs/factor_model_lgbm.yaml
```

### 6.3 Feature AttentionNN

Feature AttentionNN learns dynamic weights over the current timestamp's factor vector.

Input:

```text
current timestamp's 60 factor values
```

Structure:

```text
60 factors
→ feature embedding / attention module
→ weighted representation
→ 2-hidden-layer MLP head
→ prediction
```

Typical architecture:

```text
feature embedding dim: 32
attention hidden dim: 64
MLP head hidden dims: [128, 64]
output dim: 1
```

Important note:

```text
Feature AttentionNN is not a temporal model.
It does not explicitly look back over past timestamps.
```

Train:

```bash
nohup python -u src/train_attention_nn.py \
  --config configs/factor_model_attention.yaml \
  > logs/train_attention_h60_202410_100.log 2>&1 &
```

Outputs:

```text
outputs/hidden_factor_attention_h60_202410_100.csv
outputs/model_metrics_attention_h60_202410_100.csv
outputs/attention_weight_summary_h60_202410_100.csv
models/attention_h60_202410_100.pt
```

### 6.5 60-layer Residual MLP

The 60-layer MLP is implemented as a residual MLP instead of a plain fully connected stack.

Reason:

```text
A plain 60-layer MLP may suffer from optimization instability.
Residual connections make the deep MLP easier to train.
```

Structure:

```text
input projection
→ 30 residual blocks
→ 2 linear layers per block
→ about 60 hidden linear layers
→ output layer
```

Train:

```bash
nohup python -u src/train_mlp.py \
  --config configs/factor_model_mlp60.yaml \
  > logs/train_mlp60_h60_202410_100.log 2>&1 &
```

Outputs:

```text
outputs/hidden_factor_mlp60_h60_202410_100.csv
outputs/model_metrics_mlp60_h60_202410_100.csv
models/mlp60_h60_202410_100.pt
```

### 6.6 Lookback AttentionNN

Lookback AttentionNN is the temporal model.

Input:

```text
past 60 windows × 60 factors
```

For each stock and date:

```text
X_t = [
    factors at t-59,
    factors at t-58,
    ...
    factors at t
]

y_t = label_60 at t
```

Output:

```text
hidden_factor_lookback_attention_h60
```

It uses causal self-attention over time, so the model only attends to current and past positions.

Train:

```bash
nohup python -u src/train_lookback_attention.py \
  --config configs/factor_model_lookback_attention.yaml \
  > logs/train_lookback_attention_h60_202410_100.log 2>&1 &
```

Outputs:

```text
outputs/hidden_factor_lookback_attention_h60_202410_100.csv
outputs/model_metrics_lookback_attention_h60_202410_100.csv
outputs/lookback_attention_weight_summary_h60_202410_100.csv
models/lookback_attention_h60_202410_100.pt
```

Because this model requires a lookback window, the first few rows of each stock-day may not have predictions.

## 8. Evaluation Metrics

Evaluation is performed on the out-of-sample test period:

```text
20241030 to 20241031
```

Main metrics:

```text
overall_ic
overall_rankic
mean_cs_ic
mean_cs_rankic
cs_icir
cs_rankicir
mean_long_short
long_short_ir
mean_group_1 ... mean_group_5
```

The most important metrics for this stage are:

```text
mean_cs_rankic
cs_rankicir
mean_long_short
long_short_ir
```

### Cross-sectional RankIC

For each timestamp:

```text
RankIC_t = SpearmanCorr(pred_i,t, label_i,t across stocks)
```

Then average over timestamps:

```text
mean_cs_rankic = mean(RankIC_t)
```

This is important because market-making and stock selection decisions rely on relative strength across stocks at the same timestamp.

### Long-short return

At each timestamp:

```text
1. Sort stocks by hidden factor
2. Split into 5 groups
3. Long group 5
4. Short group 1
5. Compute group_5 return - group_1 return
```

## 13. Notes

### Current label is raw future return

The current training target is raw `label_60`, not a cross-sectional label.

A possible future improvement is to train on a cross-sectional label:

```text
label_60_cs = cross-sectional z-score of label_60 by datetime
```

or:

```text
label_60_rank = cross-sectional rank of label_60 by datetime
```

This may improve stability for cross-sectional IC tasks.

### Current project direction

For now, the project direction is time-series prediction, so the models continue to predict raw `label_60`.

### Feature AttentionNN vs Lookback AttentionNN

```text
Feature AttentionNN:
    Uses current timestamp's factor vector.
    Learns attention over features.
    Does not explicitly look back.

Lookback AttentionNN:
    Uses past 60 windows of factor vectors.
    Learns temporal attention over historical states.
```

### Use the same test period for fair comparison

All hidden factors and raw factors should be evaluated on the same test period when comparing results.
